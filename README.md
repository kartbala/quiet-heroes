# Quiet Heroes

One person a day who did the right thing when nobody was watching. Large type,
high contrast, and a narrated version of every story.

Live: https://kartbala.github.io/quiet-heroes/

## How it works

- `heroes.json` holds every entry: name, one-line blurb, anchor date and why,
  a 120 to 200 word story written to be read aloud, a one-line note on anything
  contested, and the sources used to verify the date and the story.
- `index.html` shows the hero for the viewer's local date. If there is none on
  that date it shows the most recent one. `?id=<slug>` shows a specific hero;
  `?date=MM-DD` shows a specific date.
- `browse.html` lists everyone by month.
- `audio/<id>.mp3` is the narration, generated by `generate_audio.py` with
  ElevenLabs using a cloned voice. The API key is read from `~/.env~` at run
  time and never stored in the repo.
- No build step, no framework. Plain HTML, CSS, and JavaScript.

## Adding a hero

1. Add an object to the `heroes` array in `heroes.json`. Check that no other
   entry uses the same month and day.
2. Verify the date against two sources and list them in `sources`.
3. Run `python3 generate_audio.py` to make the missing MP3.
4. Run `python3 check.py` to validate, then commit.

## Design

Borrowed from the signage language of balasubramanian.org: near-black
background, white text, retroreflective yellow accent, Atkinson Hyperlegible
for body text and Overpass for display. Base font size is 21px. Today's hero
name is at least 64px on desktop and the story at least 30px.
